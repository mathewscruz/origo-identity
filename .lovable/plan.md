

## Plano: Atualizar AZURE_CLIENT_ID

O `AZURE_CLIENT_ID` atual não é reconhecido no tenant "ORIGO ENERGIA". Vamos solicitar o valor correto via `update_secret`.

### Ação
- Usar a ferramenta `update_secret` para pedir ao usuário o **Application (client) ID** correto do App Registration no Azure Portal (Entra ID → App registrations → seu app → Overview → Application (client) ID).
